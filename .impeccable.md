# .impeccable.md — LOGIK LAB Design Authority (Versión 1.0 / Noviembre 2026)

## Marca
- **Nombre**: LOGIK LAB — Software Engineering
- **Naturaleza**: Firma de ingeniería de software a la medida y estudio de arquitectura de producto digital. **NO es una agencia de marketing ni de plantillas web**.

## Esencia Visual (Tres Decisiones)
1. **Geometría amable (`Aa`)**: Terminaciones redondeadas y trazos contundentes, con un lenguaje cercano y tecnológico.
2. **Contraste radical (`01/02`)**: Negro (`#000000`) y blanco (`#FFFFFF`) como estructura (contraste 21:1 AAA). Azul eléctrico (`#075FFF`) como firma de reconocimiento.
3. **Piezas autónomas (`[ ]`)**: Separación entre signos y componentes: un lenguaje modular que sugiere construcción y adaptabilidad.

## Sistema de Marca (Tres Recursos)
- **Firma principal**: `Logik SOFTWARE ENGINEERING LAB` (`/brand/logo-full.png`). Mínimo digital: `640 px`.
- **Logotipo abreviado**: `Logik` (`/brand/logo.png`, `/brand/wordmark.png`). Mínimo digital: `180 px`.
- **Isotipo autónomo**: Dos trazos separados: barra vertical blanca y ángulo azul (`#075FFF`) de vértice izquierdo (`/brand/isotype.png`). Mínimo digital: `40 px`.
- **Espacio de seguridad**: `X = 10%` de la altura visible del recurso en sus cuatro lados.

## Paleta Maestra Verificada (Estricta)
- **Azul LOGIK** (`#075FFF`, `RGB 7 / 95 / 255`): Acento e identidad.
- **Negro absoluto** (`#000000`, `RGB 0 / 0 / 0`): Fondo principal.
- **Blanco** (`#FFFFFF`, `RGB 255 / 255 / 255`): Logotipo y textos principales.
- **Gris descriptor** (`#B4B4B4`, `RGB 180 / 180 / 180`): Apoyo tipográfico y descriptores.
